# RentalOCarz

Car-rental enquiry website for [rentalocarz.com](https://rentalocarz.com). Phone: (888) 383-9487.

```bash
npm run dev   # http://localhost:3000
npm run build
```

Contact details live in `lib/site.ts` and can be overridden via `NEXT_PUBLIC_*` env vars; set `LEAD_WEBHOOK_URL` to deliver quote-form leads to your CRM.
